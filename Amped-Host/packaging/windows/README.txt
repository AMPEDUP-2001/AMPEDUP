AMPEDUP! - PRIVATE EXPERIMENTAL WINDOWS BUILD

This is a work-in-progress build for personal use on your own PCs. It was built
from the European multilingual Amped game executable, and the compiled program
contains recompiled code derived from that game. The package does not include
the game's disc assets. Do not publish or redistribute this personal package.

Requirements: 64-bit Windows 10/11, a Vulkan-capable GPU and current driver,
about 3 GB of free space, and the exact XISO used for this build (SHA-256:
1DCAF6F4C5385B90987A0DB33CBC34ED408982995DFE3A5B68DCFAD70CA91CB0).
Other editions or differently packaged images have not been validated.

1. Open Setup-AMPEDUP.exe. Select your matching ISO and installation folder,
   choose whether to create a desktop shortcut, and press Install. The folder
   must not already exist; Browse chooses a parent and appends 'AMPEDUP'.
   For now, use short ASCII-only image and installation paths without commas.
2. Start AMPEDUP! from the desktop shortcut or installed AMPEDUP!.exe.

F1 or Xbox View/Back + Menu/Start opens the graphics settings. The default
profile uses 16:9, 4x internal resolution, 16x anisotropic filtering, CRT
scanlines and a 60 FPS guest-flip cap. Anti-aliasing starts off; FXAA and SMAA
are available. If a setting needs a restart, choose Yes to apply it now or No
to cancel the change. In the resolution prompt, use left/right to choose
the scale and up/down to choose No or Yes. Restarting loses unsaved progress.
Choose Quit Game at the bottom of settings and press the select button again
to exit.

Saves, settings and logs are in the installed folder's profile subfolder.
Back up profile before moving or removing the installation. The profile is not
automatically imported from a previous diagnostic build. To uninstall, close
the game, back up profile if desired, delete the installation folder and its
desktop shortcut. A failed installation leaves its incomplete destination for
inspection; choose a new destination or remove it manually.

The game remains experimental. CRT scanlines affect the final game image
including video and the game's HUD; the host settings overlay is not filtered.
Some video paths may not yet preserve their original aspect. No guarantee of
60 displayed FPS or support for HDR and all game modes is made.
