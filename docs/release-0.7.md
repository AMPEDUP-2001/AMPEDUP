# AMPEDUP! 0.7

## Add your music in-game

Open **Options → Soundtracks** and press **Y** on a controller or **Ctrl** on
the keyboard to choose a music folder. Each folder becomes an extra genre.
Import supports MP3, FLAC, WAV, and Ogg Vorbis, including tracks in album
subfolders. AMPEDUP! keeps your original files and saves converted copies
in your local profile. Existing genres stay available.

After import, choose **Yes** to restart and load the new genre or **No** to
load it next time. Open Soundtracks to toggle each genre independently with
**X**. Accept with **A** and use **Save As Defaults** to retain the selection.

## Install on Windows

Choose the online installer, the all-in-one installer, or the Windows x64
ZIP for RecompLauncher. Each builds from the supported European multilingual
retail XISO. The all-in-one installer includes the build tools. The other
two download them during setup. RecompLauncher reruns Easy Setup for this
version and keeps game saves in the profile. Imported music stays local.

The 4:3 and 16:9 tests at 4× internal resolution verified folder selection,
restart, and playback of imported tracks on Snow Summit 1.
