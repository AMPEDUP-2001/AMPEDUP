# AMPEDUP! 0.8.1

**Potato Mode** is an optional graphics preset for slower PCs. Open **Options → Graphics → Potato Mode**, switch it **On**, and confirm the restart. You can also open Graphics with **F1** or **View + Menu** on an Xbox controller.

The preset uses original 1× resolution, original textures and a 30 FPS cap. It turns off anti-aliasing, anisotropic filtering and CRT scanlines. The rider keeps its original shadow. Fullscreen, aspect ratio, audio, controller settings and saves stay yours. Turn Potato Mode off and confirm the restart to return to your previous graphics settings.

RecompLauncher also offers the switch before launch. When updating, let it finish preparing the new runtime from your game files. The playable release is for **Windows x64**. The [Linux development handoff](https://github.com/AMPEDUP-2001/AMPEDUP/releases/download/v0.8/AMPEDUP-0.8-Linux-Codex-Handoff.zip) is available separately for developers.

On a desktop Intel UHD 770 restricted to two physical CPU cores, the preset averaged about 28 displayed FPS in a short Brighton replay sample. Performance on Intel HD/UHD 620 laptops still needs player testing.
